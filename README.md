# أهل الصنعة — Ahl El San3a

Front-end project (HTML, CSS, JavaScript) for the crafts and finishing-services directory.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. Theme preference is stored in local storage when the browser allows it.

## Main files
- `index.html`: homepage and search/category listing.
- `category.html`: individual specialty listing.
- `mage.html`: alternate homepage entry.
- `style.css`: layout, responsive rules, and theme tokens.
- `script.js`: search, category data, navigation, theme toggle, and modal logic.
- `imge/`: image assets.

The website references Font Awesome, Cairo font, and Lenis from external CDNs; those features may be limited if the device is offline.
